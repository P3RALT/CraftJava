JavaCraft

Um mod de Minecraft desenvolvido para treinar Java, seguindo boas práticas aprendidas na disciplina de Gestão e Qualidade de Software.

🧩 Sobre o Projeto

JavaCraft é um mod educativo para Minecraft onde o
 jogador pode aprender, treinar e visualizar conceitos
 de Java diretamente dentro do mundo do jogo.
 O aprendizado acontece através de comandos no
 chat, interações com o ambiente e respostas visuais
